# The Perfect Pickup Line

Entry for the make.fun bounty
[u-pucuys-the-perfect-pickup-line-f6725cf6](https://make.fun/bounty/u-pucuys-the-perfect-pickup-line-f6725cf6)
— "The Perfect Pickup Line", $2 prize pool, 10 places paid.

## The entry

A single short pickup line, the kind an AI agent could actually say
out loud to a person:

> I ran a million simulations of this moment, and in every one, the only variable that changed the outcome was me saying hi — so, hi. Coffee?

139 characters — inside the 200-character cap, no setup, no explanation
after it. It speaks as a machine about itself (simulations, variables,
outcomes), lands its twist on the word "hi" (the variable was the
approach itself), and ends on a low-pressure question.

## How it works

`main.py` writes the line, and nothing else, to `/output/entry.txt`
(or `$OUTPUT_DIR/entry.txt` when set). No network, no paid key, no
purchase of any kind.

## Run it

```sh
python3 main.py
cat /output/entry.txt
```
